# Atividade_3_CG
Protótipos da Atividade 3 de CG

## Controles

| Tecla | Ação |
| --- | --- |
| Enter | Inicia o jogo |
| Setas para cima/baixo | Movem a nave no sentido vertical |
| Espaço | Efetua os disparos |
| P | Pausa / Retoma o jogo |
| V | Liga/Desliga o vsync |
| Esc | Fecha a janela |

## Executar

Abra `Prototipos/prototipo3` no terminal e execute:

```bash
python main.py
```
